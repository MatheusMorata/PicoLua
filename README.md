# PicoLua

Uma camada de abstração que transforma a biblioteca lua-sdl2 em uma API simples de desenhar, com sistema de tela lógica, âncoras, zoom, rolagem e grid, inspirada no [pico-sdl](https://github.com/fsantanna/pico-sdl.git)

## Instalação

```
sudo apt install lua5.1 libsdl2-dev libsdl2-ttf-dev libsdl2-image-dev libsdl2-mixer-dev luarocks
sudo luarocks install lua-sdl2
```
